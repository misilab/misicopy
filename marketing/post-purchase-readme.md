## ⚡ Installation en 30 secondes

1. **Téléchargez** l'app depuis : https://misiraca.com/misicopy/download
2. **Ouvrez** le fichier `MisiCopy-1.0.dmg`
3. **Glissez** l'icône MisiCopy dans le dossier Applications
4. **Lancez** MisiCopy depuis Applications ou Launchpad
5. À l'ouverture, ouvrez les **Réglages (⌘ ,) → onglet Licence**
6. Collez votre email d'achat et votre clé → cliquez **Activer**

La pastille verte « LICENCE » apparaît en haut à droite — c'est bon, profitez !

## 🚀 Workflow recommandé

### Plateau / tournage
1. Configurer vos destinations habituelles (1× HDD plateau, 1× SSD backup)
2. Activer les 3 boutons rapides : **Surveillance** + **Auto-start** + **Auto eject**
3. À chaque carte branchée, MisiCopy s'occupe de tout : copie, vérification, éjection, rapport PDF
4. La carte verte = OK = vous la pouvez la formatter

### Studio / post-prod
1. Définir un profil par projet (mode, algorithme, renommage, destinations)
2. Utiliser le renommage par tokens : `{date}_{source}_{counter:04}.{ext}`
3. Exporter le rapport ASCMHL v2 à livrer au monteur

## 📚 Conseils & astuces

- **xxHash3** est l'algorithme par défaut — le plus rapide et le standard pro actuel
- Mode **Double vérification** = source relue après copie pour détecter les bits flips (recommandé pour archive long-terme)
- **Mode surveillance** ne marche QUE si vous avez désactivé le sandbox dans Xcode pour votre propre build, sinon l'app .dmg téléchargée fonctionne directement
- Les rapports PDF sont écrits **à la racine de chaque destination** automatiquement à la fin de chaque copie
- L'**historique** garde les 500 dernières sessions avec leurs stats — utile pour audit

### Problèmes fréquents

**« Carte détectée — couldn't be opened because you don't have permission »**
→ macOS Sequoia (15+) restreint l'accès aux volumes amovibles. Dans Réglages système → Confidentialité et sécurité → Fichiers et dossiers → MisiCopy → cochez « Volumes amovibles ».

**« Essai expiré » alors que j'ai acheté**
→ Vérifiez Réglages → Licence. Saisissez votre email exact (sensible aux majuscules) et la clé sans erreur de copie.

**Comment changer de poste ?**
→ Sur l'ancien poste : Réglages → Licence → « Désactiver sur ce poste ». Puis activez sur le nouveau avec la même clé.
