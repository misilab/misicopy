# Bienvenue sur MisiCopy

Merci pour votre achat ! Voici comment démarrer.

---

## 📥 Installation

1. Ouvrez le fichier **MisiCopy-1.0.dmg** que vous avez téléchargé
2. Glissez l'icône **MisiCopy** dans le dossier **Applications**
3. Lancez MisiCopy depuis Applications ou Launchpad

---

## 🔑 Activer votre licence

1. Ouvrez les **Réglages** : menu **MisiCopy → Réglages** (ou **⌘ ,**)
2. Cliquez sur l'onglet **Licence**
3. Collez votre clé dans le champ **Clé de licence**
4. Cliquez **Activer**

La pastille verte **LICENCE** apparaît dans le coin haut-droit de la fenêtre. C'est bon !

> Votre licence couvre **2 ordinateurs**. Pour activer le second Mac, installez l'app et collez la même clé.

---

## 🆘 Questions fréquentes

**« Carte non détectée » sur macOS Sequoia (15+)**
Allez dans **Réglages système → Confidentialité et sécurité → Fichiers et dossiers → MisiCopy** et activez **Volumes amovibles**.

**Je veux changer d'ordinateur**
Sur l'ancien Mac : Réglages → Licence → **Désactiver sur ce poste**. Puis activez la même clé sur le nouveau.

**J'ai perdu ma clé**
Vérifiez l'email envoyé par Payhip après votre achat (objet : *Votre commande chez MisiRaca*). Si vous ne la retrouvez pas, écrivez-moi.
